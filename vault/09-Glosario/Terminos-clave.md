# Glosario de Términos Clave

## A–C

- **Autenticación**: Verificar identidad (email+password)
- **CRUD**: Create, Read, Update, Delete
- **Controller (Controlador)**: Coordina flujo MVC
- **Commit atómico**: Un cambio lógico por commit

## D–M

- **DBMS**: Sistema gestión BD
- **DocumentRoot**: Carpeta pública servidor
- **FK (Foreign Key)**: Clave foránea (relación)
- **Front Controller**: Punto entrada único
- **JOIN**: Unión tablas
- **Model (Modelo)**: Datos + lógica BD
- **MVC**: Model-View-Controller
- **MySQL/MariaDB**: RDBMS

## P–Z

- **PDO**: PHP Data Objects
- **PK (Primary Key)**: Clave primaria
- **Prepared Statement**: Consulta parametrizada
- **PR (Pull Request)**: Solicitud fusión GitHub
- **Routing**: Mapear URL→acción
- **SQL Injection**: Ataque inyección SQL
- **View (Vista)**: Presentación HTML
- **password_hash/verify**: Hash contraseñas
- **Session**: Estado entre peticiones
- **utf8mb4**: Charset Unicode completo
